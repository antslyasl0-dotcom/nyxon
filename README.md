# NYXON

تطبيق إدارة أندية برو كلوب لكلان NYXON: صدارة اللاعبين، المباريات، الحضور،
التشكيلات، البطولات.

اللاعب يفتح الرابط ويتفرج **بدون أي حساب**. الدخول بقوقل مطلوب فقط لمن يبي
يأكد حضوره أو يدير.

---

## التشغيل في ثلاث خطوات

### ١. مشروع Firebase  (~٥ دقائق، مرة وحدة)

في <https://console.firebase.google.com>:

1. **Add project** ← سمّه `nyxon` ← عطّل Analytics ← Create
2. **Build ← Firestore Database ← Create database ← Production mode**
3. **Build ← Authentication ← Get started ← Google ← Enable ← Save**
4. **⚙ Project settings ← Your apps ← `</>`** ← انسخ `firebaseConfig`

### ٢. عبّي الإعدادات

سمِّ `config.example.js` باسم **`config.js`** والصق فيه القيم.
خلّ `ownerUid` فاضي — الصفحة التالية بتعطيك إياه.

### ٣. شغّل الموقع ثم افتح صفحة الفحص

ارفع المجلد (GitHub Pages أو <https://app.netlify.com/drop>)، ثم افتح
**`setup.html`** على موقعك. هي تمشّيك لآخر الطريق:

- تفحص `config.js` وتقول لك وش ناقص
- تسجّل دخولك بقوقل وتعرض **معرّفك** جاهز للنسخ
- تبني لك **قواعد الحماية ومعرّفك مدرج فيها** مع زر نسخ
- تتأكد إن القراءة والكتابة اشتغلت فعلاً

> بعد ما ترفع الموقع: Firebase ← **Authentication ← Settings ← Authorized domains**
> وأضف دومين موقعك. بدونها الدخول بقوقل ما يشتغل.

### ثم انقل بياناتك

من داخل التطبيق: **الإدارة ← نسخة احتياطية ← استورد** واختر `nyxon-data.json`.

## الملفات

| الملف | وش يسوي |
|---|---|
| `index.html` | التطبيق |
| `setup.html` | صفحة فحص الإعداد — ابدأ منها |
| `nyxon-runtime.js` | طبقة تربط التطبيق بـFirebase |
| `config.example.js` | انسخه إلى `config.js` وعبّيه |
| `firestore.rules` | قواعد الحماية (تُلصق في Firebase، لا تُرفع) |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | عشان ينتصب كتطبيق بأيقونته |
| `nyxon-data.json` | بيانات للاستيراد |
| `SETUP.md` | الشرح المطوّل |

## الأيقونة على الجوال

- **آيفون:** سفاري ← مشاركة ← *إضافة إلى الشاشة الرئيسية*
- **أندرويد:** كروم يعرض *تثبيت التطبيق* لحاله

## ملاحظة أمان

قيم `config.js` **ليست أسراراً** — كل موقع Firebase يعرضها في المتصفح.
الحماية كلها في `firestore.rules`: من غير ما تنشرها، أي أحد يقدر يكتب في
بياناتك. لا تتأخر عليها.
